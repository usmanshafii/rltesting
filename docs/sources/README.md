# Sources behind the engine signature (and the solar calibration it uses)

Every engine number in `thermal/engine_heat.py`, `target/engine_l550e.py` and `configs/signatures.yaml` traces to
one of the documents below, or is labelled as an estimate. Which component uses which source, for the whole
project: [`SOURCES_GUIDE.txt`](../../SOURCES_GUIDE.txt). Tiers follow the source rule in `CLAUDE.md`:

* **S1**: authoritative and about the exact item (manufacturer datasheet, manual or drawing of the item; a standard;
  a regulator's document; a peer-reviewed measurement of the item).
* **S2**: authoritative, about a close analogue or general physics (another manufacturer's manual for a comparable
  product, a peer-reviewed paper or thesis with its method, a standard textbook or handbook, a government research report).
* **S3**: secondary (encyclopedia, vendor white paper or application note quoting values without their conditions,
  trade press). Used only to find an S1/S2 source or as a cross-check.
* **S4**: weak, not used (forums, blogs, marketing and distributor listings, search-engine snippets, AI-generated text,
  unsourced specifications, including this project's own spec, which records decisions, not evidence).

## What is saved, and how to repeat every reading

Each source has a folder holding the document, images of the pages cited, any images taken from it, and the data
read off it. PDFs and images are third-party material: kept here locally and git-ignored (`.gitignore`); the
SHA-256 lets anyone check that a downloaded copy is the same document. The data files are committed:

| File | What | Made by |
| --- | --- | --- |
| `limbach/measurements.json` | Drawing scales (from each drawing's own dimension lines), fin pitch and thickness, cylinder-end width, the four width lines (410 / 363 / 314 / 178 mm), stack diameter and position, vertical dimensions (fin height, stack end, carburettor bottom) | `python tools/source_measurements.py` |
| `limbach/sfc_chart_digitised.csv` | L550E full-throttle SFC curve, 4,125-7,375 rpm | same |
| `naca/fig9_digitised.csv` | NACA 488 fig. 9: q at 0.175 and 0.164 in fin space for 30-150 mph, fitted slopes | same |
| `naca/fig9_points.csv` | The 162 raw points read off fig. 9 (speed, fin space, q) behind those fits | same |
| `astm/band_integrals.csv` | ASTM G173-03 (extraterrestrial, global tilt, direct) and E490 in-band irradiances over the renderer's bands (RGB r/g/b, SWIR 0.9-1.7 µm, LWIR 8-14 µm) and the tables' totals | same |
| `astm/e490_am0_model_grid.csv` | ASTM E490 AM0 spectral irradiance on the thermal model's wavenumber grid (700-2800 cm-1 every 5 cm-1, W m-2 (cm-1)-1; log-log interpolation of the E490 table), full double precision: the MWIR sun reads it (`thermal/atmosphere_bands._e490_grid`), so a copy of the code without the git-ignored workbook export renders identically (tested) | same |
| `iau/constants.json` | IAU 2015 B3 nominal solar radius, irradiance and temperature; IAU 2012 B2 astronomical unit | same, from the PDF's text layer |
| `hirth/readings.json` | Hirth 2301 specific fuel consumptions (cross-check) | same, from the PDF's text layer |
| `limbach/visual_readings.json` | Readings by eye on the datasheet photos and text: heat-sink fin count (12 ± 2), fin orientation, black finish, the width lines with and without heat sinks, "air cooled ... suitable for pusher and tractor installations" | by hand, with the images named |
| `ausserer/quotes.txt` | The passages used, with their printed page numbers | by hand, from the PDF |

`tests/test_engine_heat.py` ties the model to these files: `target/engine_l550e.py` must equal
`measurements.json` and `sfc_chart_digitised.csv`, and the NACA 488 anchor must reproduce `fig9_digitised.csv`.
`tests/test_glow_and_glints.py` ties `configs/signatures.yaml` to `astm/band_integrals.csv` and the code's Sun to
`iau/constants.json`. Every derived engine number (heat balance, cooling, contrast, plume, glow, glints) is saved in
`docs/reference/engine/data/` by `python tools/engine_report.py`. Retrieved 2026-10-10 unless noted.
